LUXE BY SOPH — PORTABLE WEBSITE
================================

This package is a complete static website. It does not require a database,
server-side code or a special framework.

HOW TO PUBLISH
--------------
1. Extract the ZIP file.
2. Upload all extracted files and folders to the hosting provider's public
   website directory. This may be named public_html, www, htdocs or similar.
3. Keep the assets folder beside index.html.
4. Point the chosen domain name at the hosting provider.

The website will open from index.html. Phone booking links use Soph's number:
07944 756991.

PACKAGE CONTENTS
----------------
- index.html — page content and structure
- styles.css — design and mobile layout
- script.js — automatically updates the copyright year
- assets/ — the flyer and beauty photographs

COMPATIBILITY
-------------
Suitable for static hosting platforms including Cloudflare Pages, Netlify,
GitHub Pages, cPanel hosting and Amazon S3 static website hosting.

No build command is needed. If a platform asks for a publish/output directory,
select the folder containing index.html.
